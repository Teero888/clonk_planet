Keyboard and Gamepad Control

Every player may choose one of four sections on the keyboard with ten redefineable keys each, or use a gamepad, if available. In each round, control methods are assigned to the participating players, depending on availability. Use the options in the menu system to customize your control methods.

Movement

The six bottom keys of a player keyboard block provide clonk movement commands: ⬈ throw, ⬆ up, ⬋ dig, ⬅ left, ⬇ down, ➡ right. To enter a building, stand in front of the building’s entrance and click ⬆ up.

 

Digging

On command ⬋ a clonk will start digging diagonally into the ground. While digging, the direction can be altered using ⬅ left and ➡ right. Left rotates digging direction clockwise, right counter-clockwise. On ⬇ stop the clonk will stop digging. By clicking the dig key again while the clonk is already digging, transportable chunks of material can be dug free. This works with materials such as earth, sand, and ice.

 

Dig Double Click

Special construction commands can be given by clicking dig twice quickly ⬋ ⬋:

•Create a new building with a construction kit
•Connect lines with a line construction kit
•Build bridges with loam or metal
•Chop down a tree if the clonk holds no special object

 

Construction

Construction sites are marked with a white sign. With a double stop ⬇ ⬇ clonks can be assigned to start working at that site.

 

Collecting Objects

Clonks will automatically pick up small objects when in range. Most clonks can carry only one object at a time. This object is displayed in the player’s status bar. In order to pick up another object, the clonk will have to throw away or drop the object first. At times it will be useful to put down an object rather than throwing it (i.e. flintstones). This can be achieved with the quick keyboard combination double stop throw ⬇⬇⬈. After dropping an object, clonks will wait for another two movement commands before picking up objects again.

 

Grab Objects

Most larger objects can be grabbed and pushed around.

•To grab an object (i.e. the lorry), stand in front of it and double click stop ⬇ ⬇. To let go of the object, use double stop again. While grabbing, use left and right to push the object. Click stop once to hold the object in place.
•Some objects are too heavy for one clonk to push, so you will have to grab it with several clonks at a time.
•If an object is stuck in the ground with a corner, dig free that corner first.
•To straighten up a turned object, use command ⬆ up.
•To push one object into another (i.e. the lorry into a building), hold the object in front of the other’s entrance and click ⬆ up. Note that the exact center of the object being pushed will have to be in front of the entrance.
•To put a small object into another object (i.e. a rock into the lorry), grab the object and click ⬈ throw. If the clonk is carrying an object, he will put it into the object being grabbed. If not, a menu will open to pick up any object that’s contained in the larger object.

 

Activities Inside Buildings

When a clonk is inside a building, there is a number of things he can do.

•Put down an object: If the clonk is carrying an object, he may put it into the building with command ⬈ throw.
•Activate objects: With an additional command ⬈ throw the building’s activation menu can be opened. All activated objects are placed outside the building in front of the entrance.
•Exit: Use command ⬇ down to leave the building.
•Buy and sell: If the building is a home base (it has a flag), the buy menu can be activated with ⬆ up and the sell menu can be activated with ⬋ dig. If a new object is bought for a player, it is placed inside the building and needs to be activated in order to use it.

 

Menu Control

Use ⬅ left and ➡ right, ⬆ up and ⬇ down to select a menu item, ⬈ throw to confirm and dig ⬋  to close the menu. In single line menus, up and down will serve for confirmation and cancelation also.

 

Player menu

At any time during the game, a player may open a special menu using the ■ key. This menu will allow a player to determine which opponent players his clonks are to attack, to surrender a game or have another player join the game.

 

Clonk Selection

Each player can control all of his clonks or any combination of his clonks in real time. Selection of the clonks currently controlled is done with the top three buttons of the player keyboard block: ⬅ cursor left, ■ selection toggle, ➡ cursor right.

 

➡ ➡ If you select a clonk using the cursor left/right keys and then use any of the movement keys, that single clonk will be selected for control.

➡ ■ If you select a clonk using the cursor left/right keys and then click selection toggle once, that clonk is added to or removed from the current selection. In this manner, any combination of clonks can be set.

■ If you just click the selection toggle key without pressing any other selection key before, all clonks currently selected are deactivated and all other clonks are activated. In this manner you may quickly switch back and forth from controlling a single clonk to controlling all remaining clonks.

■ ■ If you click the selection toggle key twice quickly without pressing any other selection key before, all clonks will be selected.
