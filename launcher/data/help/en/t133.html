Game data

 

Clonk game data is organized in compressed group files which may contain data components or further data groups.

 

Player files (c4p)

 

Player files contain a player's scores, statistics, and permanent crew information.

 

Scenarios (c4s)

 

Scenario files contain settings for a game world. They may contain a landscape with specific weather conditions or complex mission objectives.

 

Object definitions (c4d)

 

Object definitions contain data needed for game objects such as living beings, buildings, vehicles that appear in a game world.

 

Scenario folders (c4f)

 

Scenarios can be organized in folders.

 

System data (c4g)

 

The game's graphics, sounds, and other data.
