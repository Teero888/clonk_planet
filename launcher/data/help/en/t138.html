Networking

 

Playing in a network is the best way to make use of clonk's multiplayer capabilities. An unlimited number of players can act in the same game world, working cooperatively or against each other, without being able to see directly what an opponent might be up to.

 

Synchronization

 

The clonk network works by a peer-to-peer principle. That means, the complete game is processed independently on each computer and only player commands and messages are exchanged through the network. For this to work out, all participating computers have to be perfectly synchronized. All have to be using the exact same scenario and object data, since only one small action running differently on one computer might cause the complete following course of the game world to run astray.

 

Network neighbourhood

 

In the Windows network neighbourhood, you need to install the 'client for Microsoft networks', one adapter for your local network card and the TCP/IP protocol connected to your network card. Usually, you will have to assign IP addresses to each of your networking computers manually. We recommend IP addresses such as '192.168.1.1', '192.168.1.2', and so on and a subnet mask of '255.255.255.0'. If all is setup correctly, you can see and access the other network computers in your Windows Explorer. If this doesn't work, check your Windows network setup, otherwise you won't be able to play clonk across the network.

 

Activating the clonk network

 

In the menu system's network options, activate networking and enter the addresses of all other computers in the network that you would like to be checked for running network games to the host address table. In local area networks, the computer name as used by Windows works as address. In other cases, enter the correct IP address. Make sure you use the correct IP address according to the way to want to access a remote computer. If accessing through local networks, use the address specified as network card adapter (i.e. Novell 2000 Adapter) by that computer's IP configuration. If you want to access a computer via the internet, you will have to use its address as specified by the PPP adapter (i.e. dial-up network).

 

Synchronous start

 

To start a network game, select the scenario and participating players on the first computer and click 'start'. Enable 'wait for clients' and start the game. The first computer is now the host of the game. It will start the engine and wait for other participants.

 

On all other computers, select additional players that wish to join. Enter the first computer's address into the host address table if you haven't done so already. The menu system will search for the game on the host computer and retrieve game information which is then placed in the scenario folder 'Network'. From that folder, select the scenario and click 'join'.

 

As soon as all client computers have joined, hit 'Enter' on the host computer and the game will start.

 

Runtime join

 

Runtime join is available in the registered version only.

 

The menu system will constantly scan other computers in the network for running games and place reference information in the network scenario folder. At any time, you may select one of those scenarios and click 'join'. A runtime may take anywhere from a few seconds to a few minutes, depending on the size of the scenario, because all runtime data has to be transferred from the host to the joining client computer.

 

Runtime join is recommended for local area networks only.

 

Player join

 

On any computer in a clonk network game, one to four players can play at any time. The player files (c4p) need only be stored on the computer at which the players actually sit. Players can also join or leave during game via the player menu.

 

MessageBoard

 

Hit F2 during game to type in a message for other players.

 

Synchronization loss

 

If for whatever reason a network game is interrupted due to synchronization loss, the host will automatically kick the concerned client computers so the game can continue. Most likely, synchronization was lost because players were using different sets of object definitions on their computer. Make sure the very same object packs are activated on each machine and try again.

 

Multiple client connect

 

A known problem is that once the first client has connected to the host, all following clients cannot establish a connection and output a 'No games found on host computer' message. This is a problem within the Windows network and will hopefully be fixed in future versions of clonk. Usually it helps, if clients try to join in different order.
