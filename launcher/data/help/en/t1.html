This window provides access to all game data.

 

Player files, scenario folders (books), and object folders can be expanded with a double click to show their individual contents (i.e. crew members or scenarios). Clicking with the right mouse button opens a context menu.

 

Player files, crew members, and object folders can be activated for usage in the next round by clicking the adjacent check box.

 

To start a round, select the desired scenario item and click 'Start'.

 

All objects can be organized by drag 'n' drop. Additional game elements can be dragged from external sources and dropped into the view to specific folders or the working directory. In this manner, bitmap files can be imported as portraits for player files.
