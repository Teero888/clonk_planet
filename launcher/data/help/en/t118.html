Determines which object definitions are to be loaded by this scenario. Only loaded definitions are available during game.

 

Local object definitions are stored within the scenario file and are always loaded.

 

In the menu system's main view, separate packs of object definitions can be activated or deactivated (standard objects are always activated). Most scenarios will load all activated packs. This way you can choose which objects you want to use before each round.

 

Some scenarios are designed to use specific object definitions only. Those scenarios contain an internal preset list of packs they require and will ignore the user's selection of activated packs.
